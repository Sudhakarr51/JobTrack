# JobTrack – Job Application Tracker

JobTrack is a project designed to help users organize and track their job application process in one place. It is developed as a portfolio project to practice programming, application development, and project management.

## Project Overview

Applying for multiple jobs can make it difficult to remember application details and track progress. JobTrack aims to provide a centralized way to manage job application information and monitor application status.
